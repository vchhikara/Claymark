# Help

## Opening a document

Use **Open file** on the welcome screen or in the drawer (`Ctrl+O`), or drag a `.md` file onto the window. Recently opened files are listed in the drawer.

You can also select text on any web page, right-click, and choose **Open selection in Claymark**.

## Editing

Press **Edit** (or `Ctrl+E`) to switch into edit mode. Use the formatting toolbar for Bold, Italic, Code, List, and Link — or `Ctrl+B`, `Ctrl+I`, `Ctrl+K` inside the editor.

## Saving

- `Ctrl+S` saves in place, if the document is writable.
- **Save as…** (`Ctrl+Shift+S`) always opens a picker for a new location.
- With **autosave** on, a file you opened from disk is written back a moment after you stop typing.

## Search

`Ctrl+F` opens the search bar. `Enter` / `Shift+Enter` move between matches. While editing, a Replace row is also available.

## Outline

**Outline** lists the document's headings; choose one to jump to it.

## Opening Claymark

Click the toolbar icon, or press `Alt+Shift+M`. You can change the shortcut at `chrome://extensions/shortcuts`.
